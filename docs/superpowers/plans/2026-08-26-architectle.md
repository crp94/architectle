# Architectle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a daily architecture deduction game — name the architect from a widening crop of a building — with a fully validated curated pool and an indexable archive.

**Architecture:** Next.js 16 App Router, statically generated. All game logic is pure functions in `src/lib/` with no React dependency, so it is unit-testable in isolation. The building pool is hand-authored TypeScript compiled to JSON by a validating curation script that is a CI gate. Images are downloaded from Wikimedia Commons once, optimised, and committed, making builds offline-deterministic.

**Tech Stack:** Next.js 16 · React 19 · TypeScript 5 · Tailwind CSS 4 · Vitest · Playwright · sharp · tsx

**Spec:** `docs/superpowers/specs/2026-08-26-architectle-design.md` — read it before Task 1. This plan argues from it and does not restate its reasoning.

## Global Constraints

- Node 22.x. Pin with `.nvmrc` (`22`), `engines.node` `>=22.0.0 <23`, and `.npmrc` `engine-strict=true`.
- Zero secrets required to build, test or deploy. No runtime API keys, no database.
- No hardcoded hex colours in components. Every colour comes from `src/lib/theme.ts`.
- No hardcoded player-facing English in components. Every string comes from `src/lib/i18n.ts`, complete in `en`, `es`, `it`.
- No dark mode. One palette.
- Licences accepted for images: `CC0`, `CC BY 2.0/3.0/4.0`, `CC BY-SA 2.0/3.0/4.0`, `PD`. Nothing else.
- Every prose block in curated data carries at least one `Source`. Unsourced prose is a validation failure.
- Every `LocalizedString` is complete in all three locales or curation fails.
- `npm run check` = `data:curate && lint && typecheck && test`. It must pass before any task is called done.
- Commit after every task. Conventional commit prefixes (`feat:`, `test:`, `chore:`, `data:`).

**Spec refinement adopted here:** `Architect` gains a `gender: 'woman' | 'man' | 'non-binary' | 'unknown'` field (Wikidata P21). The spec's ≥20% coverage target cannot be validated without it.

- [ ] **Step 5: Run and watch fail, then implement `coverage.ts`**

Buckets keyed on `completed ?? inception`. Rules and thresholds copied verbatim from spec §7.3:

| rule | threshold |
|---|---|
| `era-pre-1800-min` | ≥10% |
| `era-1800-1945-min` | ≥25% |
| `era-1945-2000-min` | ≥40% |
| `era-post-2000-min` | ≥15% |
| `geography-europe-max` | ≤45% |
| `geography-north-america-max` | ≤25% |
| `geography-asia-min` | ≥15% (Eastern, Southern, South-eastern Asia) |
| `geography-africa-west-asia-min` | ≥12% |
| `geography-latin-america-min` | ≥10% |
| `gender-min` | ≥20% of architects `woman` or `non-binary` |
| `max-buildings-per-architect` | ≤3 |
| `canon-tier-min` | ≥60% of buildings are `tier: 'canon'` |

Each violation's `detail` must state the measured value and the threshold, e.g. `"Europe 62.5% exceeds maximum 45%"`. A validator that says only "failed" is useless to the curator.

```ts
export const EPOCH = Date.UTC(2026, 8, 1); // 2026-09-01, launch day
const DAY_MS = 86_400_000;

export function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export function shuffledCycle(n: number, cycleIndex: number): number[] {
  const rng = mulberry32(0x9e3779b9 ^ (cycleIndex * 2654435761));
  const a = Array.from({ length: n }, (_, i) => i);
  for (let i = n - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

// Uses the LOCAL calendar date, normalised through Date.UTC, so the puzzle turns
// over at the player's midnight and is immune to DST shifts.
export function localDayIndex(now: Date): number {
  const utcOfLocalDate = Date.UTC(now.getFullYear(), now.getMonth(), now.getDate());
  return Math.floor((utcOfLocalDate - EPOCH) / DAY_MS);
}

export function puzzleNumber(now: Date): number {
  return localDayIndex(now) + 1;
}

export function dailyIndex(now: Date, poolSize: number): number {
  if (poolSize <= 0) throw new Error('poolSize must be positive');
  const d = localDayIndex(now);
  const cycle = Math.floor(d / poolSize);
  const pos = ((d % poolSize) + poolSize) % poolSize;
  return shuffledCycle(poolSize, cycle)[pos];
}
```
